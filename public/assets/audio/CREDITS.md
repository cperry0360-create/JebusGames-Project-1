# Audio credits

## Kenney — CC0 1.0 Universal (public domain)

32 of the game's 41 cues come from Kenney's free audio packs, fetched from the
GitHub mirror at <https://github.com/ETdoFresh/kenney.nl> by `tools/getsfx.py`,
which records exactly which file became which cue.

| Pack | Used for |
|---|---|
| Impact Sounds | tower fire, enemy hits and deaths, hero hits, wave bell |
| Interface Sounds | clicks, errors, confirmations, menu open and close, scratching |
| UI Audio | hover |
| RPG Audio | building, coins for peanuts and for the Politician's tax |

Kenney's packs are released under CC0: no attribution is required. This file
exists because they deserve it anyway. <https://kenney.nl/>

## Recorded for this project

Three cues are voice lines, all recorded by **Elijah** and original to this
project:

| Cue | Line |
|---|---|
| `sfx-goblin-spawn.wav` | the goblin's greeting, once per run, as the first enemy comes out of the entrance arch |
| `sfx-haymaker-voice.wav` | the Haymaker landing |
| `sfx-dadmode-voice.wav` | DAD MODE |

They ride a bus of their own so the three can be balanced as a group, and
everything else steps back while one is talking.

## Synthesised for this project

The remaining six cues are the multi-second *stings* — the Last Stand
transformation, the boss entrance, the Server Nuke, the last life, and the two
run endings. None of Kenney's packs contain anything of that shape; they are
all short one-shot impacts and interface blips. These are generated by
`tools/mksfx.py` with the Python standard library and are original to this
project.
